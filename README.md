# Lista de Contatos

Projeto pessoal desenvolvido para consolidar conhecimentos em Java.
Em constante evolução conforme avanço nos estudos.

## Sobre

Sistema de gerenciamento de contatos via terminal — permite adicionar,
listar, buscar e remover contatos com validação de dados.


## Funcionalidades

- Adicionar contato/emergência com nome, celular e email
- Listar todos os contatos/emergência
- Buscar contato/emergência por nome
- Remover contato/emergência

> Novas funcionalidades serão adicionadas conforme o projeto evolui.

## Tecnologias

- Java
- Maven
